## 实时核对规则

1. 读取当前日期，不沿用 Skill 中的历史模型名或价格。
2. 分别在四家官方页面确认当前最新、可通过 API 调用、适合通用 Agent 的主力模型。
3. 区分“厂商最新发布”“当前 API 可用”“当前 Hermes 可配置”。三者不一致时明确说明，只推荐真正可交付的模型。
4. 从官方页面提取：准确模型 ID、更新时间或快照、中文与通用能力、视觉输入、工具调用、上下文、输入与输出价格、免费额度或最低充值限制。
5. 官方未写明的能力标记“未确认”，不从模型名称推断。
6. 价格标明币种、每百万 Token 或套餐单位和核验日期；不把网页聊天免费额度当成 API 免费。

## 本地免费模型

检测到 Ollama、LM Studio 等本地模型时，单独增加“本地免费方案”，不要混入四家云 API 的价格比较。

- “免费”仅表示没有按次 API 费；仍有下载、磁盘、内存、电力、硬件和时间成本。
- 检查模型许可、官方模型地址、文字/视觉/工具能力、本机内存、实际上下文和首次响应时间。
- 真实运行后检查服务报告的上下文，而不是只看模型理论上限。实际上下文低于 Hermes 当前最低要求、响应过慢或工具调用失败时，不推荐为主模型；可以保留为辅助视觉模型。
- 本地模型未完成文字、图片和至少一次无副作用工具调用测试前，不能显示“可用”。
